- kalo AI layer -> untuk generate, classify, extract, summarize

- ! frontend itu ada proses build sebelum kita serve aplikasinya, jadi dinamik value kodenya menjadi di-hardcode semua, file statis.
- jadi tidak disarankan API key langsung di frontend. API key (call model) harus melalui backend

### ==Architecture-nya==
```md
User -> React-Vite -> Hono API -> AI Workflow -> Database
```

- UI Library -> satuan
- Framework -> satu bundle/satu paket/ready to use component
- react itu UI library

- javascript yg dipelajari di sini punya 2 runtime (alat untuk menjalankan sebuah script)
	- nodejs -> pnpm init, di-serve ke nodejs -> bisa langsung jalan
	- browser -> pnpm init, di-serve ke browser -> butuh proses Build
- di proses build ada 2 hal terjadi
	- transpiling -> meneranslate bahasa asli ke javascript (bahasa yg dipahami oleh runtime browser)
	- bundling -> mengumpulkan semua assets (html, js, css, image, video, etc) dalam project ke menjadi satu kesatuan
- Vite -> tools/framework yg ngejalanin proses Build/bundling
- untuk membuat project dengan vite -> ==`pnpm create vite`==
