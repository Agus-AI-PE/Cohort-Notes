- monorepo itu apa?
- satu repository dengan mutiple project, service, lib yang berbeda-beda
	- jadi tinggal dimasukin ke dalam satu folder project-nya? nope.
	- memahami monorepo -> 1. punya satu konteks dalam satu repo project; 2. sebagai toolchain (CI/CD);
- design system -> set of style token yang harus diikuti semua product dalam satu company
- benefit monorepo di era AI
	- ai agent butuh ngerti konteks, codebase, flow backend dan frontend. dengan monorepo langsung kelihatan semua
	- mudah juga untuk ngerti end-to-end nya tanpa buka repo lain di IDE lain

### ==Workspace Setup==
- buat foldernya lalu run perintah `pnpm init` kemudian `pnpm i`
- lanjut install `pnpm i typescript tsx @types/node -D`
- ![Pastedimage20260709225321367](https://raw.githubusercontent.com/Agus-AI-PE/notes-media/main/Pastedimage20260709225321367.png)
	- apps/** -> untuk dedicated app; punya entry point sendiri (server listen di port, build buat di-serve); meng-import dari packages
	- packages/** -> code yang reusable/di-share; lib yang dipake oleh satu atau lebih apps
- seperti -> ![Pastedimage20260709225757282](https://raw.githubusercontent.com/Agus-AI-PE/notes-media/main/Pastedimage20260709225757282.png)
- ![Pastedimage20260709230051655](https://raw.githubusercontent.com/Agus-AI-PE/notes-media/main/Pastedimage20260709230051655.png)
- struktur folder jadi seperti ini
- ![Pastedimage20260709230301767](https://raw.githubusercontent.com/Agus-AI-PE/notes-media/main/Pastedimage20260709230301767.png)
- tambahin .env di root
- install dengan `pnpm i dotenv-cli -w` -> tambah flag -w untuk install di workspace
- ![Pastedimage20260709230948554](https://raw.githubusercontent.com/Agus-AI-PE/notes-media/main/Pastedimage20260709230948554.png)
- tambahkan script `with-env` pada level app-nya untuk membaca value dari env yang ada di level workspace
- bedanya import untuk nodejs as runtime dan browser as runtime
	- nodejs runtime -> process.env.EXAMPLE_VALUE_BE -> process hanya bisa dibaca di nodejs
	- browser runtime -> import.meta.env.EXAMPLE_VALUE_FE
