## ==*So...*==
![Pastedimage20260703030525586](https://raw.githubusercontent.com/Agus-AI-PE/notes-media/main/Pastedimage20260703030525586.png)
- akan ada 3 macam db yang akan dipelajari 
	- in-memory database (KV) -> redis 
	- relational database -> postgres
	- vector database -> db untuk menyimpan vector untuk melakukan pencarian secara semantic

- prisma? ORM -> object relation mapping -> untuk mempermudah dev melakukan komunikasi dengan db -> tidak pakai raw sql
- components prisma ORM
	- prisma schema -> mendefinisikan model
	- prisma migrate -> tools tersendiri untuk manage dari perubahan-perubahan table
	- prisma client -> utility, menggunakan bahasa typescript untuk berhubungan meminta data dengan db bukan dg bahasa query
	- prisma studio -> inspect db secara visual, kayak phpmyadmin/supabase dashboard

- install prisma dengan run `pnpm i prisma`
- next run `pnpm prisma init` -> untuk menginisiasi project dengan menggunakan prisma dan akan mendapat 2 generate file baru: prisma.config.ts dan schema.prisma 
- ==bikin model di schema.prisma==
- ![Pastedimage20260703063742114|466](https://raw.githubusercontent.com/Agus-AI-PE/notes-media/main/Pastedimage20260703063742114.png)
	- @id -> primary key
	- String? -> question-mark itu artinya optional di field tsb
	- @default -> value default pada kolom tsb

- configurasi postgres dengan docker
- docker-compose.yml -> sebuah declaration file yang bisa buat define sebuah service
- ![Pastedimage20260703063956833](https://raw.githubusercontent.com/Agus-AI-PE/notes-media/main/Pastedimage20260703063956833.png)
	- ports -> untuk expose. yg kanan port asli. yang kiri port forwardingnya
	- volume -> kayak harddisk yg diattach ke dalam suatu buah docker service
		- yang kiri virtual disk
		- yang kanan path mappingannya
	- image di docker itu kayak iso
- jalankan docker service dengan perintah `docker compose up -d` flag -d artinya dijalankan di background
- di .env -> connection string nya sesuaikan dengan yang barusan diconfig
	- `postgres://username:password@host:port/database_name`

- setelah service sudah ready untuk mendengarkan migrasi db, jalankan perintah untuk melakukan migrasi 
	==`pnpm prisma migrate dev`== -> untuk run di local
	`pnpm prisma deploy` -> untuk di prod -> tidak membuat file migrasi baru
- setiap kali melakukan migrate re-run lagi `pnpm prisma generate` agar type-nya update
- akan men-generate migration file, setiap run perintah prisma migrate history log nya akan tercatat di sana dan file .sql nya (raw query)

- ==run `pnpm prisma studio` untuk membuka tool prisma studio==

- kalau  dotenv value-nya -> undefined; pake aja dotenv-cli kemudian tambah script di package.json
	- `"with-env": "dotenv -e ./.env --"`
- script dev dan worker:dev menjadi 
	- pnpm with-env tsx watch src/index.ts
	- pnpm with-env tsx watch src/worker.ts

- ==prisma client== -> perlu package lain
- prisma client -> mempermudah dev yg terbiasa dg typescript untuk mengkonek/berkomunikasi dengan db menggunakan ts bukan raw query
	- `pnpm i @prisma/client @prisma/adapter-pg`
	- @prisma/client -> ulitity untuk bicara dengan postgres-nya
	- @prisma/adapter-pg -> translatornya
- generate prisma client berdasarkan schema model yang dibuat dengan perintah
